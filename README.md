# Шизофрения — учебный стенд контекстного ИИ-собеседника для Twitch

Проект для учебного эксперимента по гуманизации диалога с локальными и облачными LLM.

## Структура проекта
- `browser_extension/` — расширение Chrome/Edge (Manifest V3) для чтения чата из DOM, генерации ответов через Ollama / OpenAI-совместимые API / Gemini и контролируемой отправки.
- `chat_sim/` — локальный симулятор 20 виртуальных участников и генератор JSONL-логов.
- `chat_app/` — локальный веб-интерфейс и очередь с ручным подтверждением.
- `twitch_client/` — неактивный модуль официального Twitch OAuth/Helix/EventSub.
- `tests/` — модульные тесты Python и Chrome Headless V8 JS-тесты.

## Быстрый старт (расширение + Ollama без лимитов)
1. Установите [Ollama](https://ollama.com/download) и скачайте модель (например, `ollama pull qwen3:8b` или `ollama pull qwen2.5:7b` / `gemma3:4b`).
2. Разрешите браузерным расширениям обращаться к локальной Ollama (один раз в PowerShell) и перезапустите Ollama:
   ```powershell
   setx OLLAMA_ORIGINS "chrome-extension://*"
   ```
3. В Chrome/Edge откройте `chrome://extensions/`, включите **Режим разработчика** (*Developer mode*), нажмите **Загрузить распакованное расширение** и выберите папку `browser_extension`.
4. Откройте панель расширения, укажите:
   - **Разрешённый канал** (логин канала, например `mishakuhn`)
   - **Управляющие пользователи** (логины через запятую)
   - **Аккаунт бота** (ник, под которым вы вошли в Twitch)
   - **Модель** (например `qwen3:8b`, `qwen2.5:7b` или `gemma3:4b`)

## Как обновлять у напарника
После `git push` напарник запускает `update_extension.bat` в корне репозитория и нажимает **↻ Обновить** на странице `chrome://extensions/`. Локальные настройки и ключи хранятся в `chrome.storage.local` браузера и при обновлении не стираются.

## Проверка тестов
```powershell
python -m unittest discover -s tests -v
```
