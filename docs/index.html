💊 Шизофрения

Браузерный ИИ-собеседник для Twitch-чата на базе локальной модели и памяти персонажа.

✅ Архив Shizics-main.zip начал скачиваться! Следуйте пошаговой инструкции ниже.

📋 Пошаговая инструкция для чайников

Шаг 1. Установите Ollama (мозги для бота)
  1. Скачайте и установите Ollama для Windows.
  2. Откройте PowerShell (Поиск Windows → PowerShell) и один раз выполните команду, чтобы Chrome пускал запросы к Ollama: setx OLLAMA_ORIGINS "chrome-extension://*"
  3. Обязательно полностью перезапустите Ollama: нажмите правой кнопкой по значку ламы у часов (в трее) → Quit Ollama, и запустите Ollama заново из меню Пуск.
Шаг 2. Скачайте модель под ваш компьютер
Откройте PowerShell и вставьте одну из команд в зависимости от вашей видеокарты:
  • 8 ГБ видеопамяти (GTX 1070, RTX 3060/4060 — оптимально): ollama pull qwen3.5:9b
  • 4–6 ГБ видеопамяти (слабый ПК / ноутбук): ollama pull qwen2.5:7b или совсем лёгкую: ollama pull gemma3:4b
  • 16+ ГБ видеопамяти (мощный ПК): ollama pull gpt-oss:20b
Шаг 3. Установите расширение в Chrome
  1. Нажмите кнопку выше и скачайте Shizics-main.zip.
  2. Распакуйте архив в любую постоянную папку (например, C:\Shizics — не запускайте прямо изнутри ZIP!).
  3. Внутри папки запустите install_extension.bat — он сам скопирует нужный путь и откроет страницу расширений Chrome.
  4. В правом верхнем углу Chrome включите тумблер «Режим разработчика» → нажмите «Загрузить распакованное расширение» → вставьте путь (Ctrl+V) и нажмите Выбор папки.
Шаг 4. Настройка и запуск на Twitch
  1. Откройте стрим на Twitch (например https://www.twitch.tv/mishakuhn) и нажмите на иконку 💊 в правом верхнем углу браузера.
  2. Заполните поля:
    • Разрешённый канал: mishakuhn (логин без #)
    • Управляющие пользователи: ники через запятую, на кого отвечать
    • Аккаунт бота: ваш собственный ник на Twitch
    • Провайдер: Ollama (локально, без лимитов)
    • URL сервера модели: http://localhost:11434
    • Модель: имя скачанной модели (например qwen3.5:9b или gpt-oss:20b)
  3. Выберите шаблон личности (например, «Лёша» или «Архивариус нижнего интернета»).
  4. Нажмите «💊 Сохранить настройки» → «Старт» → «💊 Включить авторежим».
Шаг 5. Как обновлять расширение потом
  1. Откройте корневую папку Shizics-main (на один уровень выше browser_extension) и запустите update_extension.bat.
  2. Зайдите в chrome://extensions/ и нажмите круглую стрелку «Обновить» на карточке «Шизофрения».
  3. Нажмите F5 на вкладке с Twitch.
